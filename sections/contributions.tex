\section{Team Contributions}

\subsection{Member 1 (Frontend Developer)}
	extbf{Role:} Frontend Developer

	extbf{Responsibilities:}
\begin{itemize}
\item Implement the single-page application UI and visualization components.
\item Integrate frontend with backend APIs and ensure data contracts are honored.
\item Write unit and component tests for UI logic and perform basic accessibility checks.
\end{itemize}

	extbf{Key Contributions:}
\begin{itemize}
\item Implemented the Dashboard, Feature Explorer, and Forecast Comparison components used for exploratory analysis.
\item Added interactive visualizations with Chart.js and supported CSV/JSON export functionality.
\item Wrote frontend unit tests and participated in end-to-end smoke testing to validate UI rendering and API integration.
\end{itemize}

\subsection{Member 2 (Backend Developer)}
	extbf{Role:} Backend Developer

	extbf{Responsibilities:}
\begin{itemize}
\item Implement data ingestion, preprocessing, and model training pipelines.
\item Design and maintain RESTful APIs for serving preprocessed data and forecasts.
\item Create unit and integration tests for backend components and validate model serialization.
\end{itemize}

	extbf{Key Contributions:}
\begin{itemize}
\item Implemented ingestion and preprocessing scripts to normalize heterogeneous data sources.
\item Built model training and inference endpoints using FastAPI and produced serialized model artifacts.
\item Developed backend unit and integration tests; assisted with basic load testing and profiling of inference latency.
\end{itemize}

\subsection{Member 3 (QA Engineer and Documentation Lead)}
	extbf{Role:} QA Engineer and Documentation Lead

	extbf{Responsibilities:}
\begin{itemize}
\item Design and execute the test plan for unit, integration, system, and acceptance testing.
\item Develop and maintain automated test cases and CI-friendly test harnesses.
\item Perform regression testing after feature changes and verify fixes.
\item Produce and maintain user and developer documentation, including setup guides and test reports.
\end{itemize}

	extbf{Key Contributions:}
\begin{itemize}
\item Authored the comprehensive test plan and created representative test datasets for reproducible validation.
\item Implemented automated test suites and integrated tests into CI to catch regressions early.
\item Produced testing and deployment documentation, test procedures, and troubleshooting notes used during evaluations.
\item Coordinated testing sessions, reported reproducible bug reports, and verified fixes across frontend and backend components.
\end{itemize}
